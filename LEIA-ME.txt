ATUALIZACAO DE SEGURANCA — cardapio

Conteudo: index.html + pasta assets + .nojekyll.

Como aplicar:
1. Abra o repositorio GitHub chamado cardapio.
2. Substitua o index.html existente pelo deste pacote.
3. Envie a pasta assets completa (substituindo os mesmos arquivos).
4. Mantenha o repositorio configurado em Settings > Pages > Deploy from a branch > main > /(root).
5. Aguarde o deploy e teste a pagina em janela anonima.

Protecoes adicionadas:
- Content Security Policy (CSP) restritiva para pagina estatica sem JavaScript.
- Bloqueio de scripts, objetos incorporados e envio de formularios.
- Restricao de origens de imagens, estilos e fontes.
- Referrer-Policy para reduzir envio de URL de origem a outros sites.
- rel=noopener noreferrer em links que abrem nova aba.

Observacao: o GitHub Pages nao permite definir livremente todos os cabecalhos HTTP. A CSP e a politica de referrer foram aplicadas via meta tags.
